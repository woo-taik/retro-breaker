# 게임 내용 설명서 초안 — 60초 벽돌방

아래 문안은 실제 신청서의 항목명과 선택지에 맞춰 옮겨 적는 용도입니다. 신청인이 게임의 최종 버전과 일치하는지 확인한 뒤 사용합니다.

## 기본 정보

- 게임물명: 60초 벽돌방
- 장르: 아케이드 / 퍼즐 액션
- 플랫폼: 모바일 WebView 기반 앱인토스 미니게임
- 조작: 화면을 좌우로 드래그하거나 방향키로 패들을 움직입니다.
- 이용 방식: 온라인 접속 후 1인이 단독으로 플레이합니다. 이용자 간 대전·채팅·거래 기능은 없습니다.
- 목표: 제한 시간 60초 동안 공을 반사해 벽돌을 깨고 높은 점수를 기록합니다.

## 게임 진행

이용자는 화면 하단의 패들을 좌우로 이동해 공이 바닥으로 떨어지지 않도록 합니다. 시작 시 생명은 3개이며 공을 놓칠 때마다 생명 1개가 줄어듭니다. 벽돌을 깨면 점수를 얻고, 연속으로 벽돌을 깨면 콤보에 따라 점수 배율이 높아집니다. 모든 벽돌을 깨면 다음 패턴이 나타나며, 시간이 끝나거나 생명을 모두 잃으면 해당 판이 끝납니다.

게임 결과는 점수·최대 콤보·도달 패턴으로 표시합니다. 최고기록은 이용자별로 저장될 수 있으며, 게임 순위 기능이 설정된 경우 점수를 리더보드에 제출합니다.

## 보상·결제·광고

게임 내 유료 결제, 게임머니, 재화 구매, 현금성 보상, 경품, 환전, 베팅, 도박 요소는 없습니다. 확률형 아이템도 없습니다.

선택형 리워드 광고가 설정된 경우, 첫 게임을 끝낸 이용자가 생명을 모두 잃었고 10초 이상 남았을 때에만 광고 시청을 선택할 수 있습니다. 광고 시청을 정상 완료한 경우에만 동일한 판에서 생명 1개를 받습니다. 광고를 닫거나 재생에 실패하면 보상을 받지 않습니다. 광고 보상은 게임 내 생명 1개뿐이며 경제적 가치나 현금성 가치를 갖지 않습니다.

## 콘텐츠 내용

게임 화면에는 추상적인 색상 벽돌, 공, 패들, 점수·시간·생명 표시만 있습니다. 캐릭터, 사람·동물 표현, 신체 노출, 욕설, 공포, 범죄, 음주·흡연·약물, 사행성 연출, 실제 또는 묘사된 폭력·유혈은 포함하지 않습니다. 벽돌을 깨는 표현은 색상 블록이 화면에서 사라지는 단순한 추상 효과입니다.

## 통신·개인정보

게임은 이용자별 최고기록·소리 설정·플레이 횟수를 저장할 수 있습니다. 앱인토스 환경에서 게임 순위 및 저장 기능은 플랫폼 SDK를 사용합니다. 별도 회원가입, 채팅, 이용자 간 메시지, 위치정보, 연락처 접근, 사진·카메라·마이크 권한 요청은 없습니다. 게임 분석 기능을 활성화할 경우 게임 시작·종료·광고 이용 등 서비스 품질 측정 이벤트만 기록하며, 코드에서 별도의 이용자 실명·연락처를 수집하지 않습니다.

## 이용등급 검토 의견

현재 구현 기준으로는 전체이용가 신청을 검토합니다. 근거는 위 콘텐츠 내용처럼 선정성·폭력성·사행성·공포·언어·약물·범죄 표현이 없고, 결제·환전·베팅·확률형 아이템이 없기 때문입니다. 이는 신청인의 검토 의견일 뿐이며, 이용등급과 내용정보의 최종 결정은 심의 결과를 따릅니다.
