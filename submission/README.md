# 등급분류 신청 자료 묶음

이 폴더는 **60초 벽돌방**의 게임물관리위원회 등급분류 신청을 준비하기 위한 초안입니다. 신청자 본인 정보, 최종 게임 파일, 실제 플레이 캡처는 자동으로 채울 수 없으므로 신청 직전에 직접 확인해 입력합니다.

## 포함 파일

- [게임 내용 설명서](game-content-description.md): 신청서의 게임 내용·이용 방법·등급 판단 근거에 붙여 넣을 문안
- [화면 캡처 지침](screenshot-capture.md): 심의용과 앱인토스용 원본 화면 2장씩을 확보하는 방법
- [`../public/app-icon-600.png`](../public/app-icon-600.png): 토스 콘솔용 600×600 PNG 아이콘. 배경은 불투명입니다.

## 신청 직전 채울 정보

아래 항목은 사실과 일치하는 값만 입력합니다.

| 항목 | 입력할 값 |
| --- | --- |
| 게임물명 | 60초 벽돌방 |
| 영문명 | Retro Breaker (필요한 경우) |
| 신청인 | 개인 본인 성명 또는 사업자등록증상 상호 |
| 대표자·연락처·주소 | 신청인 실제 정보 |
| 플랫폼 | 모바일 / 앱인토스 WebView |
| 희망 이용등급 | 전체이용가로 신청 검토. 최종 결정은 심의 결과를 따름 |
| 빌드 식별 | `retro-breaker.ait` 생성일·해시·버전 |
| 시험용 실행 방법 | 아래의 ‘실행 방법’ |

## 시험용 실행 방법

1. `npm ci`
2. `npm run dev -- --host 127.0.0.1`
3. 브라우저에서 표시된 주소로 접속한 뒤 **게임 시작**을 선택합니다.

배포 번들은 `npm run build`로 생성되는 `retro-breaker.ait`입니다. 앱인토스 샌드박스에서 동작을 다시 확인한 최종 번들만 제출합니다.

## 제출 전 변경 금지 항목

등급분류 증명서를 받은 뒤에는 심의 대상과 달라지지 않도록 다음을 유지합니다.

- 게임 규칙, 점수·생명·광고 보상 구조
- 광고가 보상하는 항목: 한 판당 한 번의 생명 1개, 현금·상품·환전 가치 없음
- 폭력, 선정성, 사행성, 도박·베팅, 확률형 아이템, 채팅·사용자 제작 콘텐츠 없음
- 게임명과 주요 플레이 화면

이 항목을 바꾸려면 출시 전 등급 효력과 변경 신고 필요 여부를 게임물관리위원회 또는 앱인토스에 확인합니다.
