# 60초 벽돌방

1인 개발용 앱인토스 벽돌깨기 프로토타입입니다.

## 실행

Node.js 24 기준으로 검증했습니다.

- 의존성 설치: `npm ci`
- 로컬 실행: `npm run dev -- --host 127.0.0.1`
- 게임 규칙 테스트: `npm test`
- 타입 검사·웹 빌드·앱인토스 번들 생성: `npm run build`

개발 서버 주소는 실행 로그에서 확인합니다. 생성되는 `retro-breaker.ait`는 검토용 산출물이며 자동으로 업로드되지 않습니다.

## 소스 구조

- `src/game.ts`: 생명 3개, 60초 타이머, 콤보, 피버, 6개 패턴, 충돌 계산
- `src/main.ts`: 게임 화면, 터치·키보드, 효과음, 일시정지·복귀
- `src/platform.ts`: 사용자별 SDK 저장, 로컬 미리보기 저장, 순위 제출·열기
- `src/style.css`: 반응형 레이아웃
- `tests/game.test.mjs`: 생명 소진, 다음 패턴, 콤보·피버, 타임아웃·일시정지, 측면 충돌

## 규칙

생명은 3개입니다. 5콤보부터 2배, 10콤보부터 3배 점수이며, 공을 놓치면 콤보가 초기화됩니다. 10콤보마다 패들이 5초간 넓어집니다. 모든 벽돌을 깨면 다음 패턴으로 이어지고 남은 시간과 점수는 유지됩니다. 준비 발사 시간도 60초에 포함됩니다. 탭 이탈과 일시정지는 시간을 소모하지 않습니다.

## 현재 검증 범위와 남은 작업

로컬 브라우저와 빌드 단계 검증용입니다. 토스 콘솔 앱 등록, 실제 iOS/Android 토스 앱 테스트, 실제 사용자 식별·순위 성공 검증은 별도입니다. localhost에서 순위가 성공한 것처럼 표시하지 않습니다. 브라우저의 기록과 토스 앱 기록은 분리하며 기기 간 기록 동기화는 지원하지 않습니다.

Safe Area, 뒤로가기·홈 이벤트, 종료 확인창, 분석 이벤트 훅, 선택형 광고 이어하기를 구현했습니다. 실제 네이티브 이벤트와 광고는 실기기 검증 전입니다. 등급 증빙과 플랫폼 승인 전에는 공개용 완성본으로 사용하지 않습니다.

## 광고·분석 설정

`.env.example`을 `.env.local`로 복사하고 콘솔에서 발급한 광고 그룹 ID를 `VITE_REWARDED_AD_ID`에 입력한 뒤 서버를 재시작합니다. 분석 전송은 `VITE_ANALYTICS_ENABLED=true`로 명시적으로 켭니다. 두 기능 모두 기본값은 꺼짐입니다. VITE 환경 변수는 번들에 포함되므로 비밀키를 넣지 않습니다.

첫 판을 완료한 뒤부터, 생명을 모두 잃고 10초 이상 남았으며 광고가 로드된 경우에만 이어하기를 제안합니다. 한 판당 한 번, 보상 완료 신호가 확인되면 생명 1개를 받고 일시정지 화면에서 재개합니다. 광고를 닫기만 하면 보상을 주지 않습니다. 점수와 남은 시간은 유지합니다. localhost에서는 실제 광고를 요청하지 않습니다.

`src/rewarded.ts`는 광고 상태와 중복 보상을 관리하며 `tests/rewarded.test.mjs`에서 SDK 실패·중복·지연 신호를 검증합니다. 출시 전 절차는 [RELEASE.md](RELEASE.md)를 확인합니다.
